## 🌐 소개
경영학적 사고방식을 바탕으로 사용자의 니즈를 파악하고, React와 TypeScript를 활용해 직관적이고 안정적인 웹 서비스를 구축합니다. 사용자에게 실질적인 가치를 전달하는 프로덕트를 만드는 데 집중하고 있습니다.

## 🛠️ 기술 스택 (Tech Stack)
* **Frontend**: React, TypeScript, Next.js, Vue.js, Tailwind CSS
* **State Management**: Zustand, Pinia
* **Backend & DB**: Spring Boot, Django, PostgreSQL, Redis
* **Others**: Unity(C#), Python, PyTorch

## ⚙️ 로컬 실행 방법 (Run Locally)
본 프로젝트는 **Next.js**를 사용하여 구축되었습니다.

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 기동 (http://localhost:3000)
npm run dev
```
